🐍 Python Basics – My First Projects

This folder contains my first three beginner-friendly Python programs, developed as part of my Python Learning Journey.

📌 Projects

1. Weight Converter ("weight_converter.py")

- Converts weight between Kilograms (KG) and Pounds (LBS).
- Takes weight input from the user.
- Performs mathematical conversion between the two units.

2. Temperature Converter ("temperature_converter.py")

- Converts temperature between different temperature units.
- Accepts temperature input from the user.
- Performs temperature conversion using mathematical operations.

3. Username Validator ("validate_user_input.py")

- Validates a username entered by the user.
- Checks that the username contains only 12 characters.
- Rejects spaces.
- Rejects numeric digits.
- Helps practise string handling and conditional statements.

▶️ How to Run

Make sure Python 3 is installed.

Run the programs using:

python temperature_converter.py

python validate_user_input.py
